# 🧭 Goal Step Planner using Gemini AI

A simple Python command-line app that helps you plan and refine your goals with the power of **Google Gemini AI**.  
You enter your goal — it generates clear, actionable steps to achieve it. You can then give feedback to improve or refine those steps instantly.

---

## 🚀 Features

- 🎯 **Generate step-by-step plans** for any goal
- 🗣️ **Refine plans** using your feedback
- ⚙️ Powered by **Gemini 2.5 Flash API**
- 🧑‍💻 Lightweight and beginner-friendly code
- 💡 Works entirely in your terminal — no GUI needed
